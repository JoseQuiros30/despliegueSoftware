Revisar costo y preparar proyecto GCP

nube

Esta actividad no requiere crear una VM de Compute Engine. Si abriste «Crear una instancia», pulsa «Cancelar». La aplicación se ejecutará en Cloud Run y la base de datos en Cloud SQL, creados con Terraform.

  1. Crea un proyecto GCP propio y asocia facturación.
  2. Configura un presupuesto con alertas. El presupuesto no detiene gastos.
  3. Confirma fecha y hora de eliminación prevista.
export PROJECT_ID=__PROJECT__
export REGION=__REGION__
export PREFIX=__PREFIX__
export GITHUB_OWNER=__OWNER__
export ALERT_EMAIL=__EMAIL__
gcloud auth login
gcloud auth application-default login
gcloud config set project "$PROJECT_ID"
gcloud services enable serviceusage.googleapis.com cloudresourcemanager.googleapis.com cloudbuild.googleapis.com iam.googleapis.com secretmanager.googleapis.com --project "$PROJECT_ID"

En Cloud Build → Repositories → 2nd gen, crea una conexión GitHub de nombre github en la región elegida, autoriza e instala la GitHub App en despliegueSoftware.

5

Publicar imagen inicial

nube

_DEPLOY=seed ejecuta npm, pruebas, Docker y push de :bootstrap, sin desplegar. La identidad que ejecuta el comando debe poder actuar como la cuenta Build.

export PROJECT_ID=__PROJECT__
export REGION=__REGION__
export PREFIX=__PREFIX__
export AR_REPO="$REGION-docker.pkg.dev/$PROJECT_ID/$PREFIX"
export BUILD_SA="$PREFIX-build@$PROJECT_ID.iam.gserviceaccount.com"
export CALLER="$(gcloud config get-value account)"
gcloud iam service-accounts add-iam-policy-binding "$BUILD_SA" --member="user:$CALLER" --role=roles/iam.serviceAccountUser --project "$PROJECT_ID"
cd /Applications/MAMP/htdocs/despliegueSoftware
gcloud builds submit . --region "$REGION" --project "$PROJECT_ID" --config entrega/demo-strapi/cloudbuild.yaml --service-account "projects/$PROJECT_ID/serviceAccounts/$BUILD_SA" --substitutions "_REGION=$REGION,_AR_REPO=$AR_REPO,_SERVICE=$PREFIX-service,_DEPLOY=seed"
gcloud artifacts docker images list "$AR_REPO" --include-tags
Captura: 10-imagen-bootstrap.png.

Revisar plan y aplicar infraestructura

nube

Edita el tfvars con ID de proyecto, imagen inicial, cuenta Build y correo de alertas. Lee el plan antes del apply: incluye Cloud SQL facturable.

export PROJECT_ID=__PROJECT__
export PREFIX=__PREFIX__
cd /Applications/MAMP/htdocs/despliegueSoftware/entrega/iac-strapi-gcp-cicd/infra
cp env/prod.tfvars.example env/prod.tfvars
nano env/prod.tfvars
terraform init -reconfigure -backend-config="bucket=$PROJECT_ID-$PREFIX-tfstate" -backend-config="prefix=$PREFIX/infra"
terraform fmt -check -recursive
terraform validate
terraform plan -var-file=env/prod.tfvars -out=infra.tfplan
terraform show infra.tfplan
terraform apply infra.tfplan
terraform output

Comprueba también el bucket privado __PROJECT__-__PREFIX__-uploads y su montaje en Cloud Run.
